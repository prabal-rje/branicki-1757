# R233: the nuncio Pallotto to Cardinal Francesco Barberini, 1628

- **DECODE:** record R233 ("BAV_Barb.lat_6956-19"), https://de-crypt.org/decrypt-web/RecordsView/233
- **Archive:** Biblioteca Apostolica Vaticana (BAV), Barb. lat. 6956.
- **State:** from key (the 1628 key of Norbert Biermann and Thomas Bosbach, March 2018, filed as documents on DECODE record R215, https://de-crypt.org/decrypt-web/RecordsView/215). The key is cited here, not copied.
- **Rows:** DECODE's own transcription; DECODE names its transcriber on the record. The cipher rows themselves are not in this repository.

## English gloss

A suspension of arms; the Spanish ambassador; the Duke of Mantua; the French. Fragmentary.

## The rows as read (a reading with the key)

Square brackets hold word codes. A star marks a value read from context only. `[?]` is a word code not read. '?' is a lone digit that fits no code; '~' is a gap in the transcription.

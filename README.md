# Branicki to Potocki, 22 March 1757: solved

Hetman Jan Klemens Branicki to Antoni Potocki, palatine of Bełz. AGAD 1/338/0/1/446. Scans: https://www.szukajwarchiwach.gov.pl/jednostka/-/jednostka/28224155

Catalogued as unsolved ("nierozwiązany"), and listed as catalogue 1578 in the historical cipher ledger at https://github.com/dbourdeau/cyphersolver

Solved from the ciphertext alone, and almost entirely read. Every cipher letter reads as French. Only the number code is open, mostly names and titles.

Bespoke count matching algorithm based on the French next-letter counts (deciphered 98.9% of tokens in one shot).

## Key

A reciprocal alphabet of 12 pairs. Each pair swaps: a stands for h, and h stands for a.

a-h, b-q, c-r, d-s, e-l, f-t, g-z, i-m, k-x, n-o, p-u, w-y

## Files

- `reading_446.md`: the letter in French
- `translation_446.md`: the letter in English
- `transcription_446.txt`: the cipher text, line by line
- `decryption_446.txt`: the decryption, line by line
- `clear_446.txt`: the clear parts, as written
- `key.tsv`: the key

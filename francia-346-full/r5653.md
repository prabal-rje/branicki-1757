# R5653: Rome, [after 30 August 1633]

A machine transcription of the DECODE images, made in my pipeline. Nobody verified it. Decoded with the published key and the ledger's values for some codes (see README.md). Every number here is real.

- **DECODE:** record R5653 ("ASV_i1025_SdS_Francia_346_29"), status "N/A". Archivio Apostolico Vaticano, Segreteria di Stato, Francia 346.
- **Cipher pages:** f. 310r (DECODE page 5, 7 rows).
- **Key-free check, before the key was opened:** the record fits the code counts of the earlier letters.
- **Coverage:** 162 code tokens; 155 with a value (95.7%). Three-digit tokens: 2 with a ledger value, 7 with no value. Three-digit codes: 2 with a value, 7 without.
- **Doubt:** 1 units hold a doubtful digit; 0 hold an unread sign.
- **Bits per letter** under an Italian letter model: 4.51. The same letters in a shuffled order give 8.87.

- **Heading:** my transcription notes give no heading for this page. The clear text before C01 answers the nuncio's letter "de 30. d'Ago[…]".

## Summary

Rome has seen a writing or message of Benavides about [130], and the opposite view of [330]. It returns to the same point: to press from one side and the other with the reasons given before. Rome fears that the invasion of Lorraine will cause greater trouble between the crowns.

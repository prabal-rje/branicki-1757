# DECODE's images are for research use only. No DECODE image is in this repository.
# The signs: our own machine transcription of the DECODE images, not verified. It is not in this repository,
# because DECODE marks the ciphertext of these letters as private.
# One character for each sign token of our transcription, in the same order: the shown letter, or · when the read
# shows no letter. Each break token of the transcription (a gap, joined ink, an unclassed sign, clear text, the edge
# of struck signs) shows as …. The marks _, /, [at:...] and [above:...] give no character.
# The decode has 21 letters: u stands for u and v, i for i, j and y, and c for c and k.
# The decode is not the key applied to the labels. It uses a fitted table (channel.tsv) and an order-4 letter model,
# so one label can take other letters in context. The key letter of key.tsv equals the shown letter on 0.972
# of the shown signs (real). An exact rebuild needs the letter model and our code, which we do not publish here.
